# Web Development Bootcamp — Course Work

This repository contains my **course exercises and mini-projects** from a Web Development Bootcamp, covering:

- HTML & CSS fundamentals
- JavaScript (ES6+)
- DOM manipulation
- Responsive layout (Flexbox/Grid)
- Small interactive web apps

## 📁 Structure
Folders are organized by module/topic (e.g., CSS, DOM, JS exercises, mini-apps).

## ⭐ Highlights (recommended folders)
If you’re skimming, start here:

- `17 The Dicee Game` — DOM + events
- `20 Challenge 2 - The Simon Game` — game logic + state
- `18 Advanced JavaScript and DOM Manipulation` — DOM patterns
- `4 Multi-Page Websites` — HTML/CSS structure
- `10 Grid` / `9 Flexbox` — layout practice

## ▶️ How to run
Most projects are plain HTML/CSS/JS.

1. Open any folder
2. Double-click `index.html` (or use VSCode Live Server)
